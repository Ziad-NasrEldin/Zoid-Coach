# Accepted Break Signed Acceptance

The installed signed app showed an active task and a gaming prompt with Take a break.
The action changed Today to Paused for a break, recorded exactly one response and one open break pause, and moved the task to paused.
App and helper restart preserved the paused state and answered prompt history.
Resume returned the task to active and closed the break.
Focused tests prove same-token replay applies no second task effect and open breaks suppress gaming coaching.
