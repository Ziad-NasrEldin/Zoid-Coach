1. Core thesis

Zoid Coach should turn Screenwatch from a passive log into a closed-loop accountability system. It knows what Ziad meant to do, watches what is actually happening, and chooses the smallest useful intervention.

What should Ziad do?

Use Apple Reminders, deadlines, estimates, and priorities.

What is happening?

Use Screenwatch app/window/URL metadata and screenshots only when needed.

Is there drift?

Detect gaming, distraction, unclear tasks, and avoidance patterns.

What now?

Nudge, ask, reschedule, start a sprint, or review.

2. MVP scope

The MVP should be useful immediately without building the whole final system.

Apple Reminders tasks Estimated time per task Deadline / urgency Current active task Working time Gaming / distracting time AI “Do this next” End-of-day review notification prompts No focus score for now No default hard blocking

3. Data sources

Apple Reminders

Source of truth for tasks: title, list/project, due date, status, notes, and priority.

  "actual_minutes": 0

Screenwatch

Behavior telemetry: app, window, URL, screenshots, idle state, daily log.

Installed app list

Zoid Coach should scan local apps and classify them into work, communication, research, gaming, entertainment, distracting, neutral, and unknown.

6. Behavior classification

Zoid Coach uses rules plus AI classification. Rules catch obvious patterns; AI resolves context.

Gaming

League of Legends, Riot Client, Steam, Battle.net, Epic Games, Twitch, gaming-context Discord.

Work

Cursor, VS Code, Terminal, Hermes, Figma, Notion, Reminders, work browser URLs.

Ambiguous

YouTube, Discord, browser tabs, Slack, research pages.

AI context

Use active task, URL/window title, recent app switches, and selected frames when needed.

7. Interruption levels

Level 0 — Observe

No interruption. Just log.

Level 1 — Gentle nudge

“You planned to work on X. Want to start?”

Level 2 — Accountability

“You’ve been in League for 25m. Is this intentional?”

Level 3 — Commit mode

“Pick one: 20m sprint or reschedule.”

Level 4 - Soft block

Stronger notification warning with an optional in-app overlay.

Level 5 — Hard block

Optional only. Never default.

9. Task start / stop tracking

Ziad can start a task from the dashboard, notification, or command. Zoid Coach then checks whether active behavior matches the task.

You started “Edit video intro” 4m ago but switched to League.
Was that intentional?

10. Gaming control system

Gaming should be managed as a budget and reward system, not pure punishment.

Gaming budget: 60m/day
Unlocked after: 2 priority tasks complete

Finish 90m focused work → unlock 30m gaming.

If gaming happens before work:

You used 42m gaming before completing priority work.
To unlock more, finish one 30m sprint.

Ziad can always override. Overrides are logged without moralizing and reviewed later.

13. MVP implementation phases

Phase 1 — Daily Command Center

Reminders import, task metadata, estimates, dashboard, active task, work/gaming totals, recommendation.

Phase 2 - Notification prompts

Estimate questions, drift alerts, start/reschedule/snooze buttons.

Phase 3 — Classification engine

Installed app inventory, rules, unknown app review, AI classifier.

Phase 4 — Gaming budget

Daily allowance, unlock rules, debt, overrides, soft prompts.

Phase 5 — Reviews

End-of-day summaries, tomorrow planning, weekly pattern reports.
